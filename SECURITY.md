# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `flutter_spine`, please report it privately.

**Do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to the maintainers at the address listed in the
repository's `CODEOWNERS` or contact the repository owner directly.

You should receive a response within 48 hours. If for some reason you do not,
please follow up to ensure the message was received.

## What to include

- A description of the vulnerability
- Steps to reproduce the issue
- Any potential impact or exploit scenarios
- Your suggestions for a fix (if any)

## Scope

This security policy applies to the `flutter_spine` package and its companion
packages (`flutter_core_lint`, `flutter_core_test`). Third-party dependencies
should be reported to their respective maintainers.
